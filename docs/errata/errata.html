About this report

We use the TM Forum ANL questionnaires in an assessment tool. While loading the workbooks we proof-read every text that participants see — guideline, sub-scenario descriptions, questions, options, answering guidelines and Key Effectiveness Indicators — and correct obvious errors in the tool. The original workbooks are not changed. This report lists those errors so they can be fixed at the source.

What is in scope. Real typos, wrong words, clear grammar errors and punctuation/spacing. We did not change meaning or re-word TM Forum text, and we left British and American spelling as found (fulfilment / fulfillment, behaviour). Sub-scenario names were not changed.

How to read the tables. Each row is one correction in one cell. Sheet · cell is the location in the original workbook. Text in the workbook shows the cell text around the error, with the error highlighted (⏎ marks a line break in the cell). Correction shows the original phrase struck through and the suggested text in green; a dot (·) marks a space at the start or end of a phrase. A cell with several errors appears once per error. The same error often appears in several cells (e.g. in the questionnaire sheet and again in the Scoring sheet), and each occurrence is listed.

Content issues at the end of each workbook section are problems we noticed but did not correct, because fixing them changes scoring or meaning: formula errors, criteria that disagree between sheets, copied text and leftover sheets.

Appendix A lists cells with only whitespace problems (double spaces, a space before punctuation, Chinese full-width punctuation) — minor, but they show up in the published text.
